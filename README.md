# Hibernate Learning Repository

A collection of Java examples and practice projects for learning Hibernate and JPA. The repository is organized into topic-focused folders, covering introductory concepts, entity relationships, persistence behavior, and query techniques.

## Topics

- **Hibernate fundamentals:** `HibenetIntro`, `Hibernet_intro`, `HibernetPart2`, and `HibernetPart3`
- **Persistence lifecycle and operations:** `Persietnt_lifecycle` and `Save_vs_persistent`
- **Entity relationships:** `one_to_one`, `One_To_Many&Many_to_one`, and `Many_to_many`
- **Caching:** `FirstLevelCache` and `Secondlevelcache`
- **JPA:** `JPA`
- **Hibernate Query Language (HQL):** `HQLpart-1`, `HQLpart-2`, and `HQLpart-3`

Each folder contains a separate learning example. Open a topic folder to explore its code and configuration.
