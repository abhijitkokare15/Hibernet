# Hibernate Learning Repository

This repository is a personal learning project focused on understanding Hibernate, JPA, and ORM concepts through practical Java examples. It contains topic-based examples that cover the most important areas of Hibernate development, from basic configuration to persistence lifecycle, relationships, caching, and HQL.

## About the Project

The goal of this repository is to provide a structured path for learning Hibernate step by step. Each folder is built around a concept or feature, making it easy to explore and practice one topic at a time.

The repository is designed for:
- Java developers learning ORM concepts
- Students studying Hibernate and JPA
- Developers revising persistence patterns
- Anyone practicing relational mapping in Java projects

## Main Topics Covered

- Hibernate introduction and setup
- Entity mapping basics
- Persistence lifecycle
- Save vs persistent operations
- One-to-one mapping
- One-to-many and many-to-one mapping
- Many-to-many mapping
- First-level cache
- Second-level cache
- JPA concepts
- Hibernate Query Language (HQL)

## Repository Structure

- `HibenetIntro` / `Hibernet_intro` - introductory Hibernate examples
- `HibernetPart2` / `HibernetPart3` - continuation of learning material
- `JPA` - Java Persistence API examples
- `Persietnt_lifecycle` - persistence lifecycle demonstrations
- `Save_vs_persistent` - examples comparing `save()` and `persist()`
- `one_to_one` - one-to-one association examples
- `One_To_Many&Many_to_one` - one-to-many and many-to-one mapping examples
- `Many_to_many` - many-to-many mapping examples
- `FirstLevelCache` - first-level cache examples
- `Secondlevelcache` - second-level cache examples
- `HQLpart-1` / `HQLpart-2` / `HQLpart-3` - HQL learning exercises
- `_pasted_code_` - additional sample or reference code

## Prerequisites

To run and understand the examples in this repository, you should have:

- Java Development Kit (JDK)
- Maven or Gradle (depending on the project setup)
- Hibernate library and dependencies configured
- A database such as MySQL, PostgreSQL, or any supported relational database
- A basic understanding of Java objects and SQL

## Typical Workflow

1. Review the concept folder related to the topic you want to learn.
2. Open the Java source files and entity classes.
3. Understand the mapping annotations and database configuration.
4. Run the example using the project setup.
5. Compare the output with expected database behavior.

## Why This Repository Exists

This project is not a production application; it is a study repository used to practice real-world Hibernate concepts in a simple and organized way. It is useful for building a strong foundation in persistence frameworks and relational mapping.

## Learning Goals

By working through this repository, you can learn how to:

- configure Hibernate in Java applications
- map Java classes to database tables
- work with database relationships
- manage entity lifecycle states
- optimize performance with caching
- write and execute HQL queries

## Notes

This repository reflects a learning journey and may include naming inconsistencies or project folders that are intentionally simplified for study purposes. The focus is on understanding the ideas behind Hibernate rather than building a polished production system.
